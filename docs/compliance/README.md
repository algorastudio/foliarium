dell'uso di Foliarium per la gestione di un archivio catastale storico.

## Contesto

Foliarium tratta dati personali di:

- **Possessori** registrati nell'archivio catastale (nome, cognome, paternità).
  Molti sono persone **decedute** (fuori dall'ambito GDPR, art. 2-*terdecies*
  D.Lgs. 196/2003); il trattamento riguarda principalmente i possessori
  **viventi**.
- **Utenti dell'applicazione** (archivisti, amministratori): credenziali e log
  di accesso.

Il software non tratta categorie particolari di dati (art. 9) né codici fiscali
nei dati dei possessori.
